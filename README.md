# RuneQuest Glorantha Wiki Compendium Module for Foundry VTT.

This repository hosts **releases and issue tracking** for the module. The
module content and build tooling are maintained in a separate source
repository; releases published here are built and uploaded automatically
from that source.

## Installation in Foundry

In Foundry VTT, install the module by searching for rqg wiki in Foundry instll module, or by pasting this system manifest path there:

- English: `https://github.com/sun-dragon-cult/fvtt-module-wiki-rqg/releases/latest/download/en-module.json`

## Documentation

See the [wiki module docs](https://sun-dragon-cult.github.io/wiki/wiki-module) for details.
